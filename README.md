# Configurar o setup
```bash
cd ~

sudo rm -rf ~/CURSO-TS-CETAM 

git clone -b main https://github.com/jhollyfer/CURSO-TS-CETAM.git

cd ~/CURSO-TS-CETAM

npm install --global tsx 

npm install --global pnpm

pnpm install

zed .
```


# Para executar

```bash
tsx ~/CURSO-TS-CETAM/index.ts
```

# Para executar o projeto do banco (v-1)
```bash
tsx ~/CURSO-TS-CETAM/banco-v-1/index.ts
```
